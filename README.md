# Happy-Technologies-LLC Tap

## How do I install these formulae?

`brew install happy-technologies-llc/tap/<formula>`

Or `brew tap happy-technologies-llc/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "happy-technologies-llc/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
